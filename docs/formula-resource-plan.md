# Formula Resource Plan

These OCR PDFs are registered as the app's Chinese-language formula resources:

- 方剂学: primary source for formula composition, dosage, actions, indications, contraindications, and modifications.
- 中药学: herb-level source for Chinese names, pinyin, properties, channels, functions, dosage ranges, and cautions.
- 中药药理学: pharmacology source for modern actions, safety notes, and mechanism support.

For formula ingredient records, prefer this structure:

- Formula name: Chinese, pinyin, English when available.
- Source formula actions and indications.
- Ingredient list:
  - herb Chinese name
  - pinyin
  - common English/pharmaceutical name when available
  - dose or dose range from source
  - role in formula: chief, deputy, assistant, envoy when available
  - cautions or contraindications when source-specific

Source priority:

1. 方剂学 for formula-level composition and weights.
2. 中药学 for herb-level corrections and standard dose ranges.
3. 中药药理学 for pharmacology and safety annotations.
4. External web references only as supplementary cross-checks.
