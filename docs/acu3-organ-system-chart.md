# Acu 3 Disease Chart By Organ System

Working draft for the clinical reference app. This reorganizes the Acu 3 acupuncture treatment disease roster from textbook chapter order into a Chinese Internal Medicine style organ/system order.

Source basis:
- Acu 3 / acupuncture treatment roster recovered from `针灸治疗学` table of contents.
- Sub-patterns marked `drafted` come from the pasted organ-system draft.
- Sub-patterns marked `pending` should be extracted from the specific Acu 3 disease pages before final clinical release.

Clinical safety note: this is a reference-data structure, not medical advice. Red flags and referral guidance should be stored separately and surfaced prominently in the app.

## Recommended App Fields

Use these fields for the clinical reference app:

| Field | Purpose |
|---|---|
| `id` | Stable app key, e.g. `cough` |
| `displayName` | English display name |
| `chineseName` | Chinese medical disease name where known |
| `pinyin` | Pinyin where known |
| `organSystem` | Primary browse category |
| `secondarySystems` | Cross-filtering categories |
| `sourceSection` | Original Acu 3 chapter/section |
| `patterns` | Array of pattern names |
| `patternStatus` | `drafted`, `pending_extraction`, or `verified` |
| `redFlags` | Array of red-flag prompts |
| `notes` | Short editorial notes |
